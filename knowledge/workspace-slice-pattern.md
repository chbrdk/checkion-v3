# Workspace slice pattern — CHECKION v3

Same discipline as Audion:

1. Spec (`specs/domain` + `specs/api`)
2. Contracts (`packages/contracts`)
3. Fixtures + store
4. BFF routes under `apps/web/app/api`
5. Magazine panels under `apps/web/components`
6. Pages under `apps/web/app`
7. Specs inventory + UI/API tests

Do not port v2 mega-pages. Prefer light payloads and section routes.
