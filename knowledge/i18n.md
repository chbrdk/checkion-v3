# UI locale (en / de)

**Spec:** `specs/domain/settings.md` SET-L1  
**Paths:** `paths.localeStorageKey` · `paths.i18nLibPath` · `paths.localesDir`

## Model

Brandion/Plexon-style nested JSON + `createTranslator` — no next-intl.

| Piece | Path |
|-------|------|
| Dictionaries | `apps/web/locales/en.json` · `de.json` |
| Helper | `apps/web/lib/i18n.ts` |
| Hook | `useUserPrefs().t` (same prefs as theme/locale) |

`setLocale` writes localStorage and `lang`; React re-renders chrome with the matching dictionary.

## Namespaces

`common` · `nav` · `pages` · `settings` · `home` · `projects` · `scan` · `jobs` · `results` · `domain` · `geo` · `login` · `errors`

## Out of scope

- Scan/crawl payload (URLs, axe messages, scores as numbers)
- GEO answer-insight / auto-move German product copy (`geo-insights.ts`)
- URL locale segments
