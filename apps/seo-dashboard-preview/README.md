# SEO Dashboard Preview

Standalone Vite shell for the OpenSEO-shaped Checkion SEO **Overview** + **chapter detail** magazine views (`SeoDashboardView` · `SeoChapterView` + fixtures).

```bash
cd apps/seo-dashboard-preview
npm install
npm run dev
```

Open http://localhost:5179

- Overview is the default surface
- Chapter chips + **More details** use hash routes: `#gsc` · `#keywords` · `#domain` · `#backlinks` · `#rank-tracking` · `#competitors`
